# 0003. Збірка в один HTML-файл і публікація

Статус: прийнято

## Контекст

Артефакт публікується як один HTML-фрагмент: хост сам додає `<!doctype>`, `<head>` і `<body>`. Зовнішні скрипти дозволені лише з кількох CDN, усе інше має бути вбудоване.

## Рішення

- Vite + `vite-plugin-singlefile` вбудовують увесь JS і CSS у `dist/index.html`.
- `scripts/build-artifact-page.mjs` перетворює його на фрагмент `dist/artifact.html`: спочатку `<title>` і meta (хост шукає заголовок лише в перших 8 КБ), потім стилі, вміст `<body>`, скрипти.
- CI на кожен PR запускає лінтер, перевірку типів, тести й збірку та кладе `artifact.html` в окрему гілку `build/<гілка>`, звідки її можна взяти звичайним `git fetch`.
- Публікацію виконує Claude у своїй сесії: автоматичного деплою з CI в артефакт немає.

## Наслідки

- Шрифти підключаються з Google Fonts (дозволений хост) з резервним стеком системних шрифтів.
- Розмір сторінки обмежено 16 МБ; бібліотеки обираються з огляду на розмір.
