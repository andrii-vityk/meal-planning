# 0004. Фронтенд-стек

Статус: прийнято

## Рішення

- **React 19**, лише функціональні компоненти й хуки.
- **React Compiler** (через Babel-плагін у Vite) автоматично мемоізує компоненти, тож `useMemo`, `useCallback` і `React.memo` вручну не потрібні.
- **TypeScript** у strict-режимі з `noUncheckedIndexedAccess` і `exactOptionalPropertyTypes`.
- **CSS Modules** для стилів компонентів, глобальні токени кольорів і типографіки в `src/ui/styles/global.css`, світла й темна теми.
- **Рядки інтерфейсу** — в `src/ui/strings/uk.ts` під англійськими ключами; у компонентах немає українських літералів, ідентифікатори в коді англійською, без транслітерації.
- **Тести:** Vitest + Testing Library; компоненти перевіряються через те, що бачить користувач (ролі, текст), а не через внутрішню реалізацію.
- **Лінтер:** ESLint з `typescript-eslint` (strict) і `eslint-plugin-react-hooks` (правила хуків і компілятора).

## Чому так

- React — найпоширеніший вибір із найбільшою кількістю документації; розмір бандла для цього застосунку некритичний.
- Компілятор прибирає цілий клас ручних оптимізацій, які часто роблять неправильно.
- CSS Modules не потребують рантайму й не додають залежностей.
