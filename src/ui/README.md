# ui

React-компоненти, згруповані за фічами, і хуки, що з'єднують сценарії з інтерфейсом. Тут же рядки інтерфейсу (`strings/`) і стилі (`styles/`).

- Залежить від `application` і `domain`, але не від `infrastructure`: конкретні адаптери приходять через context із точки композиції (`src/main.tsx`).
