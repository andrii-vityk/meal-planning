# domain

Сутності предметної області (продукт, рецепт, фреймворк, план) і чисті функції над ними: зведення списку покупок, покриття харчування, підбір страв.

- Не залежить ні від чого в проєкті, ні від React, ні від платформи.
- Лише детерміновані функції без побічних ефектів, тож усе тут тестується звичайними юніт-тестами.
